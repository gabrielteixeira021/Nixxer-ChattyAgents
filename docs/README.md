# Open-ChatBot Documentation

This documentation is maintained in two mirrored language trees, same filenames, same structure:

* **[docs/en/](en/)** — English.
* **[docs/pt-BR/](pt-BR/)** — Português (Brasil).

Start at [docs/en/README.md](en/README.md) or [docs/pt-BR/README.md](pt-BR/README.md) for the full documentation map.

Diagram sources and language-neutral technical contracts
([openapi.yaml](en/api/openapi.yaml),
[persona-v1.openapi.yaml](en/api/persona-v1.openapi.yaml), and the `.puml`
diagram sources) live only under `docs/en/` and are linked from both trees —
there is no reason to duplicate a YAML contract or a diagram source per
language.

A handful of historical working documents (superseded audits, dated improvement plans, an internal AI-agent-workflow archive, and a design-mockup export) live directly under `docs/` outside these two trees. They are development history, not reference documentation, and are intentionally not mirrored or translated — see the repository's `CHANGELOG.md` for what shipped.
